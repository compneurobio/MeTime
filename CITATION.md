# Citation guidance

If MeTime contributes to your analysis or publication, please cite the package.

## Suggested citation (preprint)

Marella, B., Weinisch, P., Vehovec, L., Tran V., Bless, J. J., Njipouombe Nsangou, Y. A., Kastenmüller G. & Arnold M. (2026). MeTime: An R package for reproducible longitudinal metabolomics data analysis. _aRxiv_.

## BibTeX

```bibtex
@misc{marella2026metimerpackagereproducible,
      title={MeTime: An R package for reproducible longitudinal metabolomics data analysis}, 
      author={Bharadwaj Marella and Patrick Weinisch and Lara Vehovec and Vinh Tran and Josef J Bless and Yacoub A. Njipouombe Nsangou and Gabi Kastenmüller and Matthias Arnold},
      year={2026},
      eprint={2605.08497},
      archivePrefix={arXiv},
      primaryClass={q-bio.QM},
      url={https://arxiv.org/abs/2605.08497}, 
}
```

## In R

```r
citation("MeTime")
```

Use the output to generate your bibliography entry in the required journal format.

## Suggested acknowledgement sentence

Analyses were performed using the MeTime R package for longitudinal metabolomics workflows.

## Reproducibility recommendation

When citing MeTime, also report:

- MeTime version
- R version
- Platform information (`sessionInfo()`)
