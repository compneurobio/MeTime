# Citation guidance

If MeTime contributes to your analysis or publication, please cite the preprint.

## Suggested citation

Lefebvre, H. *MeTime: an R package for longitudinal metabolomics workflows* (2026).
Preprint at arXiv. https://doi.org/10.48550/arXiv.2605.08497

## BibTeX

```bibtex
@misc{lefebvre2026metime,
  title        = {MeTime: an R package for longitudinal metabolomics workflows},
  author       = {Lefebvre, H.},
  year         = {2026},
  publisher    = {arXiv},
  doi          = {10.48550/arXiv.2605.08497},
  url          = {https://doi.org/10.48550/arXiv.2605.08497}
}
```

## In R

```r
citation("MeTime")
```

Use the output to generate your bibliography entry in the required journal format.

## Suggested acknowledgement sentence

Analyses were performed using the MeTime R package for longitudinal metabolomics workflows.

## Reproducibility recommendation

When citing MeTime, also report:

- MeTime version
- R version
- Platform information (`sessionInfo()`)
