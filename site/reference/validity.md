# Validity function to check if the object is valid or not

Function to check the validity of metime_analyser

## Usage

``` r
validity(object)
```

## Arguments

- object:

  An S4 object of class metime_analyser

## Value

logical suggesting if the object is intact or not

## Examples

``` r
validObject(object)
#> Error: object 'object' not found
```
