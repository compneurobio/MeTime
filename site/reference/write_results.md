# Function to save plot_data from an analyser_objec into an xlsx file

Saves plot_data from an analyser_objec into an xlsx file (no Java)

## Usage

``` r
write_results(object, file = NULL)
```

## Arguments

- object:

  An object of class metime_analyser

- file:

  a character defining the path where to save the xlsx file

## Value

saves all plot data in an xlsx sheet
