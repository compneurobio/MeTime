# Function to check for col_normality data whether it is added or not.

function to check whether col_normality data is added to the object or
not

## Usage

``` r
check_col_normality(object, which_data)
```

## Arguments

- object:

  S4 object of class of metime_analyser

- which_data:

  dataset/s to check

## Value

NULL if it passes all the sanity checks
