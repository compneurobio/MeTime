# Get results element by index

Get results from S4 object of class metime_analyser by a specified
index. Print object in console to see all available indices.

## Usage

``` r
get_results(object, index)
```

## Arguments

- object:

  a S4 object of the class "metime_analyzer".

- index:

  a character or numeric value defining which result should be

## Value

A list with result elements that the functions applied and type of
calculation
