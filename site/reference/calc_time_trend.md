# Calculate feature time trends

Fits a linear trend per feature over time.

## Usage

``` r
calc_time_trend(object, which_data, name = NULL)
```

## Arguments

- object:

  a S4 object of class "metime_analyser".

- which_data:

  dataset name to use.

- name:

  name for the results entry.

## Value

A metime_analyser object with results appended.
