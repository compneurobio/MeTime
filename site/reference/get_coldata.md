# Get col_data from a S4 object of the class "metime_analyser"

Get the column information of a specified dataset from a S4 object of
the class "metime_analyser"

## Usage

``` r
get_coldata(object, which_data)
```

## Arguments

- object:

  a S4 object of the class "metime_analyser"

- which_data:

  a character of the dataset name of interest.

## Value

A dataframe containing the col data of the dataset of interest.
