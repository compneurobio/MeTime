# Get parameters of the results

Get parameters and functions applied to obtain results.

## Usage

``` r
get_parameters_of_results(object, results_index)
```

## Arguments

- object:

  An S4 object of class metime_analyser.

- results_index:

  a character or numeric value to be used as the result index.

## Value

a list with all the function names and the values of the arguments
passed into it
