# Add information of function added to the data

Add information on the method applied to the metime_analyzer object.

## Usage

``` r
add_function_info(object, function_name, params)
```

## Arguments

- object:

  a S4 object of the class "metime_analyzer".

- function_name:

  a character of the name of the function that was used.

- params:

  list of parameters that were used in function.

## Value

object of class metime_analyser with the information of method applied
