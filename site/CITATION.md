# Citation guidance

If MeTime contributes to your analysis or publication, please cite the
package.

## In R

``` r

citation("MeTime")
```

Use the output to generate your bibliography entry in the required
journal format.

## Suggested acknowledgement sentence

Analyses were performed using the MeTime R package for longitudinal
metabolomics workflows.

## Reproducibility recommendation

When citing MeTime, also report:

- MeTime version
- R version
- Platform information
  ([`sessionInfo()`](https://rdrr.io/r/utils/sessionInfo.html))
